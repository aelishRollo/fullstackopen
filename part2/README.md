# Part 2

Applications used in Full Stack Open Part 2:

- `courseinfo` — runnable workspace for exercises 2.1–2.5
- `phonebook` — the existing exercise app, currently at the Part 2c/2.11 stage and ready for Part 2d
- `countries` — runnable workspace for exercises 2.18–2.20
- `notes` — the working example app at the end of Part 2c, ready for the Part 2d examples

Each directory is an independent npm application. Run commands from inside the
application directory. The Notes and Phonebook JSON Servers both use port 3001,
so run only one of them at a time.
